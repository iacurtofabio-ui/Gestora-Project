 description: Esegue dotnet test sul backend GestoraWebApi e riassume l'esito

---



 Esegui `dotnet test` nella cartella `GestoraWebApi/` del progetto.



 Al termine riporta in forma sintetica:

 - numero totale di test, passati, falliti, skippati

 - se ci sono fallimenti: nome del test e causa in una riga, senza incollare lo stack trace completo

 - se tutti verdi: una riga di conferma, nessun elenco



 Non modificare codice in questo step: se un test fallisce, fermati e descrivi il problema — la

 correzione è un passo successivo, deciso insieme.
